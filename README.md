# 📊 Super Store Excel Dashboard

## 1. 📌 Project Overview

An interactive **Excel Sales Dashboard** built using the Super Store dataset to analyze sales, profit, returns, discounts, product performance, and regional trends.

## 2. 📸 Dashboard Preview

![Super Store Dashboard](images/dashboard.png)

## 3. 🔍 Key Insights

- 📈 Phones and Chairs are the top-performing sub-categories.
- 🛑 Office Supplies has a high concentration of returned orders.
- 💰 Furniture generates high revenue, while Technology delivers stronger profitability.
- 📍 The South region shows weaker sales and profit performance.
- 📉 High discounts can negatively impact profit margins.

## 4. 🎯 Business Recommendations

1. Reduce returns by reviewing product quality and vendor performance.
2. Increase investment in high-performing sub-categories.
3. Optimize discount strategies to protect profit margins.
4. Develop a turnaround strategy for the South region.
5. Optimize low-performing sub-categories and inventory.
